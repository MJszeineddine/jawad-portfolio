# Jawad Portfolio

Client-facing portfolio for Jawad Zeineddine, Full-Stack Engineer and White-Label Engineering Partner.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- GitHub Pages static deployment

## Local Development

```bash
npm ci
npm run dev
```

## Quality

```bash
npm run lint
npm run build
```

## Deployment

The repository deploys to GitHub Pages with `.github/workflows/pages.yml`. The Vite base path is configured for:

```text
https://mjszeineddine.github.io/jawad-portfolio/
```

## Confidentiality

This portfolio contains public positioning copy, case-study summaries, and representative visuals only. It does not include client source code, credentials, production records, customer data, wallet addresses, payment details, or private documents.
